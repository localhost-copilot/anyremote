## Fixed in 0.30.1

- **The name you give a Mac is used everywhere.** After renaming a Mac in the sidebar, the picker's title, remote window titles, the Dock icons of its apps and alerts showed the name the Mac gives itself; they now show yours, like the sidebar.

## Also in 0.30

- **Apps looks like macOS's Apps view.** A row of the apps you opened lately, then every app by name in a grid of larger icons, with chips for categories such as Developer Tools or Utilities.
- **All Windows.** Windows can show every window at its own shape, as in Mission Control, besides the list grouped by app.
- **Search filters as you type,** also while a Chinese input method is still composing, and finds Chinese names by their pinyin or its initials (`jsq` finds 计算器).
- **Animations** when switching views and searching; window cards tilt toward the pointer and dip when clicked.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.30.1.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.30.1 uses protocol v23, like 0.29.x and 0.30.0, so it works with Macs still on those; app categories appear once the other Mac runs 0.30 too.
