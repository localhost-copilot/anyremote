## New in 0.26.1

- **Fixed: macOS's own prompts on the other Mac couldn't be answered from here.** A keychain or administrator password, Touch ID, a privacy permission or a warning about an app from the internet belongs to no window you opened, and macOS often put it on the virtual display that nobody sees. AnyRemote now brings such a prompt over the window you are using and shows it there. While it is open, clicking and typing in that window leave the focus with the prompt, so a password never goes to the app instead.
- Releases are now built, signed and published by GitHub Actions. They are signed with the same certificate as before, so updates keep their permissions. Each release carries a build provenance attestation: `gh attestation verify AnyRemote-0.26.1.zip -R localhost-copilot/anyremote`.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 offers this update by itself, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.26.1.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.26.1 uses the same protocol as 0.26.0 (v20), so Macs on either version connect to each other.
