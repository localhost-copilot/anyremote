## New in 0.28.0

- **Copying something large no longer slows clicks and typing.** The shared clipboard used to send everything you copied to the other Mac at once, on the same connection as your input. Now only short text goes along right away; images, rich text and long text stay where they were copied and cross only when something on the other Mac pastes them, over a connection of their own. Copies that are never pasted never cross the network.
- **Larger copies are shared.** Each type of a copy can be up to 64 MB (it was 16 MB for the whole copy).
- **One clipboard for every connection.** With this Mac connected to several others, or connected to one while hosting another, a copy is read once and passed on to all of them, and it no longer bounces back and forth between them.
- Lists, icons and the clipboard keep working when no remote window is open.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.28.0.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.28.0 uses protocol v22, so it can't connect to 0.27.x. Update every Mac: once this Mac runs 0.28.0, it offers to update the other Macs it is paired with when it connects to them.
