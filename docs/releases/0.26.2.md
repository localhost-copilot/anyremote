## New in 0.26.2

- **Fixed: AnyRemote could crash while sharing the clipboard.** With this Mac connected to another one and hosting a session at the same time, the shared clipboard read the clipboard from several places at once, which macOS doesn't support, and now and then AnyRemote quit. All of its clipboard and drag reads now take turns.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.26.2.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.26.2 uses the same protocol as 0.26.0 and 0.26.1 (v20), so Macs on any of these versions connect to each other.
