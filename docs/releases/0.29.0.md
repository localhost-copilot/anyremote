## New in 0.29.0

- **Higher frame rates.** Video Quality has a new Frame Rate setting for each Mac you control: 60 (the default), 90, 120 or 144 Hz. On a screen that refreshes faster than 60 Hz, such as a MacBook Pro's, remote windows move more smoothly. The other Mac shows its remote windows, and the full desktop when it fits your window, on a display that refreshes at that rate. A change applies to open windows right away.
- Higher rates need more of the other Mac's work and network. Large windows may not reach them, and each frame gets a little less of the video quality limit.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.29.0.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.29.0 uses protocol v23, so it can't connect to 0.28.x. Update every Mac: once this Mac runs 0.29.0, it offers to update the other Macs it is paired with when it connects to them.
