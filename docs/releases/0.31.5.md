## Fixed in 0.31.5

- **AnyRemote no longer quits while showing a remote picture.** 0.31.4 added a check that notices when a remote window or desktop stops moving. Now and then it read a frame's time just as that frame arrived, and the subtraction that followed made AnyRemote crash. The check now handles that case, and still reports a picture that really stops.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.31.5.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.31.5 uses protocol v24, like 0.31.0, so it works with Macs still on that. The fix is on the Mac you control from.
