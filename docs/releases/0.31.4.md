## Fixed in 0.31.4

- **A stuck video stream no longer stops your clicks.** When one part of a remote picture stopped being received or decoded, the Mac you control from also stopped sending clicks and keys, and the whole window could stop responding, while sound kept playing. The picture, the clicks and the window no longer wait for one another, so input keeps working whatever the video does.
- **A picture that isn't confirmed on screen no longer holds back the next.** A remote window or desktop draws its next frame once macOS confirms the previous one is shown. When that confirmation never came, the picture stayed frozen; now the next frame goes ahead after a quarter of a second.
- **Freezes leave a trace.** AnyRemote now logs when a picture stops moving, and why: frames no longer arriving, the decoder not keeping up, frames drawn but never shown, or AnyRemote itself not responding. To see it, run `log show --last 10m --info --predicate 'subsystem == "com.localhost-copilot.anyremote" AND category IN {"Stall", "Hang"}'` in Terminal.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.31.4.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.31.4 uses protocol v24, like 0.31.0, so it works with Macs still on that. The fixes are on the Mac you control from.
