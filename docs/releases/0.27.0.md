## New in 0.27.0

- **Fixed: a long list of apps could disconnect you.** The Apps list used to arrive with every app's icon in one message, several megabytes on a Mac with many apps, on the same connection as clicks, typing and the check that the other Mac is still there. On a slower network that check ran out of time and AnyRemote gave up on the connection. Lists now arrive as names alone, at once. Icons and window thumbnails follow over a connection of their own, as they are needed: an app's icon when its tile first shows, and only once per connection.
- **Smoother while the window picker is open.** Window thumbnails, refreshed every few seconds, no longer travel with your clicks and typing.
- A list that is slow to come now fails by itself and is asked for again, without disconnecting.
- **Fixed: AnyRemote could crash while sharing the clipboard.** With this Mac connected to another one and hosting a session at the same time, the shared clipboard read the clipboard from several places at once, which macOS doesn't support, and now and then AnyRemote quit.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and 0.26.1 offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.27.0.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.27.0 uses protocol v21, so it can't connect to 0.26.x. Update every Mac: once this Mac runs 0.27.0, it offers to update the other Macs it is paired with when it connects to them.
