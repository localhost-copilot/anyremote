## New in 0.32.0

- **Control your Macs from any network with Tailscale.** Turn on Settings › Tailscale › Connect Through Tailscale and sign in. AnyRemote then joins your tailnet as a device of its own, so you don't need the Tailscale app. If the Tailscale app is already connected on a Mac, AnyRemote uses it instead.
- **The local network still comes first.** AnyRemote tries every way to a paired Mac at once and uses the local network whenever it answers. This includes the addresses the Mac reported, so a Mac on another subnet that Bonjour can't find still works. The tailnet takes over when the local network doesn't answer. A connection over Tailscale says so next to "Connected", and an orange dot means it goes through a Tailscale relay.
- **Macs on your tailnet appear in the sidebar** while AnyRemote runs on them, ready to pair. Macs you paired before are recognised there by their key, so you don't have to pair them again.
- **An Info sheet for each Mac.** Choose Info… from its context menu or the menu bar panel, or press ⌘I. It shows how the Mac is connected (local network, Tailscale direct, or relay) and its addresses. You can rename the Mac, set its address, pick a route (Automatic, Local Network Only or Tailscale Only), or forget it.
- **Video and sound now use the control port's number (47800 by default) when it's free.** A firewall or tailnet access rule then needs only that one port, for both TCP and UDP.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.32.0.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.32.0 uses protocol v24, like 0.31.x, so it works with Macs still on that. To reach a Mac over Tailscale, that Mac needs either 0.32.0 with Connect Through Tailscale on, or the Tailscale app.
