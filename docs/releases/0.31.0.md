## New in 0.31.0

- **Pair with a six-digit code, like Apple devices.** Select a Mac and click Pair: that Mac shows a six-digit code in front of everything, and you type it in here. The code works once; a wrong one can be retyped. Behind it, the two Macs agree on a key with SPAKE2, so the short code can't be guessed offline, and each pair of Macs then has a key of its own.
- **Paired Macs in Settings.** Settings lists the Macs that may control this one; Remove… revokes one and disconnects it, without affecting the others.
- **Quit an app from the Windows view.** Right-click a window for Quit or Force Quit of its app.
- **Apps open with one click** in the Apps view.
- **A calmer Windows view.** Windows keep their places when another app comes to the front, a new window slides in beside its app's others, and cards no longer jump when a window changes shape a little.
- **A menu bar panel in the style of macOS's Wi‑Fi and Bluetooth panels:** a switch for letting others control this Mac at the top, then your Macs, then search and the usual commands.

Macs already paired keep working with their old code, so nothing needs pairing again. Settings › Paired Macs shows the old code as its own entry, which you can remove once every Mac has paired anew.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.31.0.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.31.0 uses protocol v24, so it can't connect to 0.30.x. Update every Mac: once this Mac runs 0.31.0, it offers to update the other Macs it is paired with when it connects to them.
