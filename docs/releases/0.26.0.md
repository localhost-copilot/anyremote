## New in 0.26.0

- **AnyRemote updates itself.** New versions download in the background and are offered with **Install and Relaunch**. If you choose Later, the update installs when AnyRemote quits. Turn it off, or check by hand, in Settings › Updates or with AnyRemote › Check for Updates…. An update is installed only if it's signed with the same certificate as the running app, so privacy permissions stay granted.
- **Update the other Macs from this one.** If a Mac you connect to runs an older AnyRemote, it shows an **Update** button. That Mac downloads the release, checks it and relaunches, and this Mac reconnects. This works for Macs running 0.26.0 or later.

## Since 0.11.1

- **Remote windows get virtual displays the size of this Mac's screens (0.23).** One per screen, so a remote window can grow as large as your screen and go full screen without moving the other Mac's windows. The displays go away when you disconnect.
- **Drag files, images and text between Macs (0.16).**
- **Type with either Mac's input method (0.12, 0.13).** Settings › Typing.
- **The other Mac can use this Mac's microphone (0.15).** Install the *AnyRemote Microphone* on the Mac being controlled: Settings › Microphone.
- **The other Mac's notifications and Dock badges show up here (0.17).** Pinch, rotate, smart zoom and swipe work too (0.18).
- **Remote apps live in Applications › AnyRemote (0.19),** so Spotlight finds them and you can keep them in the Dock. The other Mac's menu bar items work from this Mac's menu bar (0.20).
- **Video quality per Mac, and statistics over every remote window (0.25).** Window frames that show nothing new aren't sent anymore (0.24).
- Many fixes for Chrome (full-screen video, profile picker, link previews), native tabs, menus, alerts and sheets with glass, and windows that open on a virtual display.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

1. Unzip `AnyRemote-0.26.0.zip` into `/Applications`.
2. The app is signed with a self-signed certificate and isn't notarized, so clear the quarantine flag once:
   ```sh
   xattr -dr com.apple.quarantine /Applications/AnyRemote.app
   ```
3. Open it on every Mac involved, then grant Screen Recording and Accessibility and allow Local Network when asked.

Every Mac must run 0.26.0: it uses protocol v20 and can't connect to earlier versions. Each Mac needs to be updated by hand this one time. After that, updates install from the app.
