## Fixed in 0.29.1

- **Only the windows you open come over.** While you use a remote window, a window that opens on the other Mac now comes to this Mac only when your click or key caused it: a new window of the app you're using, or an app you bring forward from it, such as Finder revealing a file or a browser opening a link. Apps that someone opens on the other Mac itself, apps that start by themselves, and windows that appear in the background stay there; open them from the window list when you want them.

## Install

Requires macOS 15 or later (universal: Apple silicon and Intel).

AnyRemote 0.26.0 and later offer this update by themselves, or use AnyRemote › Check for Updates…. To install by hand, unzip `AnyRemote-0.29.1.zip` into `/Applications`. Then clear the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/AnyRemote.app
```

0.29.1 still uses protocol v23, so it works with 0.29.0. The fix is on the Mac being controlled: update the Macs you control.
